# 实践反馈 / Practice Feedback

## 中文定义

实践反馈，是指在家庭文明行动中，对一次沟通、一次道歉、一次家庭会议、一次边界表达或一次关系修复尝试进行温和复盘，指出已经发生的进步、仍然存在的伤害，以及下一次可以调整的具体方向。

实践反馈不同于批评。批评往往强化羞耻和防御，实践反馈则服务于下一次更好的行动。它关注的不是把人定性为“好父母”或“坏父母”，而是具体识别：哪些话更伤人，哪些动作更有帮助，哪些旧模式需要停止，哪些新方式值得继续。

在家庭文明工程中，实践反馈是“工程”得以持续的关键机制。文明不是一次顿悟，而是在行动、反馈、调整、再行动中逐渐建立的关系秩序。

## English Definition

Practice Feedback refers to the gentle review of a family civilization action, such as a conversation, apology, family meeting, boundary expression, or repair attempt. It identifies progress that has occurred, harm that still remains, and specific directions for adjustment next time.

Practice Feedback is different from criticism. Criticism often strengthens shame and defensiveness, while feedback serves the next better action. It does not label people as “good parents” or “bad parents,” but identifies concretely which words hurt, which actions helped, which old patterns should stop, and which new practices should continue.

Within the Family Civilization Project, Practice Feedback is a key mechanism that makes “engineering” sustainable. Civilization is not a single moment of awakening, but a relational order gradually built through action, feedback, adjustment, and further action.
