# HUMANS ARE ENDS / 人是目的

## 《家庭文明工程》的哲学基础栏目

“人是目的，不是工具”是《家庭文明工程》的最高原则之一。

这个栏目不是为了做一套枯燥的哲学史教材，而是为了回答一个更切身的问题：

> 为什么一个孩子不能被当成父母的工具？  
> 为什么一个伴侣不能被当成另一个人的工具？  
> 为什么一个普通人不能被家庭、组织、市场、技术或 AI 当成可消耗的材料？

在家庭里，如果人不是目的，爱就会变成控制；教育就会变成驯化；亲情就会变成道德绑架；婚姻就会变成消耗；AI 也可能变成新的支配工具。

因此，“人是目的”不是抽象口号，而是家庭文明、关系文明和 AI 伦理的共同根基。
