# 043. Reparative Boundaries / 修复性边界

## 定义 / Definition

**修复性边界**，修复性边界，是指在关系修复过程中，为防止伤害重演而重新建立的语言、行为、空间、情绪和人生选择边界。

**Reparative Boundaries**: Reparative boundaries are the verbal, behavioral, spatial, emotional, and life-choice boundaries rebuilt during relational repair to prevent harm from repeating.

## 核心机制 / Core Mechanism

边界不是切断爱，而是保护爱不再变成伤害。修复性边界回答的是：哪些话不能再说，哪些行为不能再做，哪些空间不能侵犯，哪些决定必须由本人承担，哪些沟通方式必须停止。

Boundaries do not sever love; they protect love from turning into harm. Reparative boundaries answer the questions: Which words must no longer be spoken? Which behaviors must stop? Which spaces must not be invaded? Which decisions must belong to the person themselves? Which communication patterns must end?

## 家庭文明意义 / Meaning for Family Civilization

家庭文明认为，没有边界的亲情容易变成占有，没有边界的婚姻容易变成控制，没有边界的父母之爱容易变成吞噬。边界是文明亲情和成熟爱的基本条件。
