# Family Civilization Project Site

This site package separates Chinese and English content:

- `/zh` Chinese site
- `/en` English site
- `/zh/books/volume-01-relationships` Chinese Volume I
- `/en/books/volume-01-relationships` English Volume I

## Upload to GitHub

Copy the `site/` folder into the repository root, or replace the existing `site/` folder. Commit and push. Vercel should deploy from the `site` directory if your Vercel project root is set to `site`; if not, set **Root Directory = site** in Vercel project settings.

## Theme image

The theme image is stored at `public/images/humans-are-ends-theme.jpg` and optimized for smaller display.
