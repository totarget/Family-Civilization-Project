# 067. 孩子太敏感，父母怎么办？

孩子敏感，不一定是缺点。

敏感的孩子可能更容易感受到情绪、气氛、他人的评价和关系变化。

问题不在于敏感本身，而在于孩子是否有能力理解、表达和安放这些感受。

父母不要说：

“你怎么这么玻璃心？”
“这有什么好难过的？”
“你就是想太多。”
“你太脆弱了。”

这些话会让孩子更加羞耻。

可以说：

“你感受到的东西比较多，这不是错。”
“我们一起看看，这个感受从哪里来。”
“感受是真的，但我们也可以一起分清事实。”
“你可以学习保护自己，而不是被每个感受淹没。”

行动方法：

第一，承认感受。
第二，帮助孩子区分事实和解释。
第三，教孩子表达：“我感到……因为……我希望……”
第四，帮助孩子建立安抚方法，如呼吸、写下来、散步、暂停。
第五，避免用嘲笑压制敏感。

一句话原则：

**敏感不是罪，缺少情绪安放能力才会让敏感变成痛苦。**
