# 031. 孩子不愿意和父母说话，怎么办？

孩子不愿意说话，通常不是因为他没有话，而是因为他说了也没有用，或者说了会带来更大的伤害。

很多父母看到孩子沉默，第一反应是逼问：

“你到底怎么了？”  
“你为什么不说话？”  
“你是不是有事瞒着我？”  
“我是你爸妈，你有什么不能说的？”

这种逼问会让孩子更不想说。

因为孩子感受到的不是安全，而是压力。

家庭文明的做法是：先建立安全，再等待表达。

父母可以这样说：

“我感觉你最近不太想说话，我不会逼你。”  
“如果你愿意说，我会听。”  
“如果你现在不想说，也没关系。”  
“我不会因为你说真实想法就惩罚你。”  

孩子愿意说话的前提，不是父母有多会讲道理，而是孩子相信：我说出来以后，不会被骂、被否定、被嘲笑、被利用。

行动方法：

第一，停止追问。  
第二，减少评价。  
第三，给孩子留出独处空间。  
第四，父母先表达自己的感受，而不是审问孩子。  
第五，孩子一旦开口，先听完，不急着教育。  

一句话原则：

**孩子的沉默，不一定是叛逆，也可能是他在保护自己。**
